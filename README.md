# 往来账龄 Skill

通过agent对话计算往来账龄，用户无需打开桌面程序或填写配置。代码和规则随技能自包含，无GUI、无原程序路径依赖。核心源自[account-aging-analyzer](https://github.com/quanfanpro-code/account-aging-analyzer)，基线提交`c96ffc7`；沿用AGPL-3.0许可，原仓库保持不变。

## 已具备的能力

- 八类普通往来及应收票据；支持完整历史从0计算、期初余额和期初账龄分档、多个截止日期。
- 暂估转正式承接原账龄；实际收付款按FIFO核销。
- 应收账款转商业承兑汇票、票据转回应收账款双向连续计龄；保留不同原始批次、部分兑付、转回、多次转科目，按原始债权日期分档。
- 应收账款与应收票据分别列示。有票据号时核销对应票据，不混用其他票据。
- 反向余额重分类及同单位成对对抵；主表与余额构成依据表均有相应备注。
- 蓝色标签标识最终结果页；其他工作表为余额构成、原账核对、重分类、对抵、暂估、票据承接及来源记录。

银行承兑和票据类型不明时，agent依据资料和会计政策确认是否连续计龄，不按“银行承兑”名称自动认定债权已终止。法规依据和适用边界见[票据连续计龄规定](references/票据连续计龄规定.md)。

## 使用

把本仓库作为`account-aging`技能供agent加载，告诉agent账表位置、截止日期和所需口径。例如：“用这份已清理账表，期初为0，计算2025年末和2026年8月末的往来账龄。”所有资料识别、必要确认、参数准备和交付均通过对话完成。

agent运行`scripts/计算往来账龄.py`的`inspect`及`calculate`模式；配置是agent的内部执行资料，不能要求用户自己写JSON。详细约定见[输入与对话](references/输入与对话.md)。运行依赖为本机Python、pandas、openpyxl；开发验证另需pytest。不得自动安装依赖或修改用户环境。

默认六档：1年以内、1—2年、2—3年、3—4年、4—5年、5年以上，按365天一年、边界归前档；用户可通过对话调整。输出另存，不覆盖源账，也不产生多份相互混淆的交付版本。

## 验证

```text
python -m pytest -q -p no:cacheprovider
```

覆盖原计算核心回归、双向票据承接、多批来源、部分收款、指定票据核销、期初分档、截止日、不同客户隔离、银行/不明票据决策、余额守恒和实际Excel导出。测试仅用模拟数据，不包含客户账表。
