# 名称候选的工商核查

仅在账内证据不足时查询候选。清洗即可确定的名称不逐个联网查询，也不开展关联方穿透、名单扩张或全维度导出。

本包内置企业搜索、登记详情、股东查询和浏览器页面取数代码。业务查询固定走最短路线：搜索企业 → 选定具体企业 → 企业详情 → 股东。不调用批量接口，不查询整套关联方维度，不做股权穿透。运行不读取其他技能目录，不要求安装名称归一或关联方识别技能。在线服务需要可用网络、查询权限及浏览器内有效登录，这些外部条件不能通过打包代码消除。

## 助手执行

调用本包`scripts/查询名称登记.py`；用本机已核实的Python运行。`--check`检查当前浏览器连接和登录；`--name`可重复指定少量需核查的名称。`--cli-path`和`--profile`只供助手根据本机实际环境指定，不要求用户填写技术路径或浏览器内部信息。

连接采用已有的OpenCLI浏览器工具与Edge扩展。先检查本机是否已经具备；缺失时说明实际缺项，按用户授权处理，不擅自全局安装组件、不另造浏览器配置。不能为了查询切换到其他技能路径。

- 登录有效：直接串行查询。搜索只有一个候选或唯一全名一致的候选时，取该企业详情和首批股东；不遍查全部候选。代码保留串行限速和有限重试，不批量并发冲击服务。
- `choose_company`：搜索有多个可能主体，助手结合原账选择具体企业，再用`--company-id`查询详情和股东。不默认选第一条，不为每条候选都查询详情。
- `partial`：企业详情或股东未取得，保留实际查到的资料并说明哪部分缺失。股东结果仅为首批，不能声称已经取得全部股东；空结果也不等于企业没有股东。
- `login_required`：必要时用`--login`在原有浏览器连接中打开官方登录页，用户在平时的Edge中正常登录；之后再次检查。不能索取、复制或保存密码和登录凭据。
- `unavailable`：先检查已连接的浏览器和扩展，重试一次；仍失败则如实记录查询未取得，保留原名，不把“没查到”改写成“两家相同”或“单位不存在”。对结果有实质影响的剩余判断集中说明。
- `no_match`：只表示本次首批检索未匹配，不能证明不存在。核对检索词、原账和其他可靠资料，不能仅因另一名能查到就自动合并。

工具只返回登记事实候选，不自动判定两个近似名称属于同一主体。助手结合统一社会信用代码、登记全称、历史名称和真实结算角色作出有据决定，写入归一配置及最终核查依据。法定代表人或股东相同不能代替同一主体。

日常用户只需要正常登录和回答真正无法从资料查明的问题，不接触上述命令与参数。
